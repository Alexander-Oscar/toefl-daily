# 英语每日 30 分钟 · 托福精听（个人版）

单文件网页应用：`index.html` 一个文件就是全部，没有任何外部依赖（不加载 CDN、不加载字体、不连任何 API），所以在国内网络下打开 GitHub Pages 就能直连使用，也不用担心某个国外服务被墙导致页面残废。

## 功能

- 今日讲座卡：自动指向第一篇未完成的讲座（Day 1 两栖动物 / Day 2 北极熊 / Day 3 冰芯与历史气候，均为考满分 ETS 官方真题链接）
- 三步流程 + 分段计时器：精听 15 分钟 → 生词 10 分钟 → 跟读 5 分钟，到时震动+弹窗提醒
- 做题分数记录：保存后自动判定难度（≥2/3 保持、≤1/3 提示降档），计入连续天数
- 生词本：只收「看了认识、听时没反应过来」的词，连原句存；可标记已掌握
- 生词复习卡：点卡片翻看原句
- 所有数据只存在自己浏览器的 localStorage 里，不上传任何服务器

## 部署到 GitHub Pages（3 步）

1. 新建一个仓库（比如叫 `toefl-daily`），把 `index.html` 传到仓库根目录。
2. 仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`，保存。
3. 等 1–2 分钟，访问 `https://<你的用户名>.github.io/toefl-daily/` 即可，手机浏览器打开后可以「添加到主屏幕」当 App 用。

## 后续加新讲座

编辑 `index.html` 里 `LESSONS` 数组，加一行 `{day:4, title:"…", topic:"…", url:"…"}` 再提交即可。
